# App7 | イロハミント 制作管理

GitHub Pagesの公開元は `main` の `/ (root)`。ビルド不要のHTML・CSS・JavaScriptで動作します。

## 依頼管理との連携

1. [依頼管理画面](https://homepage-request-sheet.netlify.app/admin.html)で対象の回答を開き、「JSONを保存」を押します。
2. App7の「依頼を取り込む」でJSONを選びます。複数の回答ファイルを選択できます。
3. 追加件数と活動名を確認して「案件に追加する」を押します。受付番号で重複を判定し、登録済みの案件は上書きしません。

活動名をお客様名と案件名に使い、連絡先、希望時期、要望などをメモに記録します。案件の公開予定日と公開URLは制作側で入力します。元の回答との連携はファイルによる取り込みです。取り込み後の変更はそれぞれの管理画面で行います。

案件データとバックアップは個人情報を含む場合があります。案件はブラウザのIndexedDBに保存されます。顧客データやバックアップはGitHubにコミットしないでください。「バックアップ」から端末間の移行ができます。

## 料金・売上

案件ごとに見積額、確定額、入金額を円単位で入力します。空欄は未入力、0円は金額が設定された状態です。分割払いでは受取済みの合計を入力してください。

- 売上見込みは全案件の確定額と、進行中で確定額が空欄の案件の見積額の合計。
- 累計確定額と累計入金額は登録済み全案件の合計。
- 未入金額は確定額から入金額を引いた残高を案件ごとに集計。マイナス分は0円として扱います。

金額はCSV出力とJSONバックアップに含まれます。従来の案件とバックアップは金額欄が空の状態で読み込めます。

## 編集・動作確認

Claude CodeでGitHubリポジトリを開き、変更をPRから `main` にマージするとGitHub Pagesに反映されます。

ローカルでは `python3 -m http.server 8000` を実行して http://localhost:8000/ を開きます。
