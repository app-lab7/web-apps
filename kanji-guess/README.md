# 11問で漢字当て

思い浮かべた漢字を、最大11回の質問で当てるWebアプリです（小学校で習う漢字1,026字が対象）。

## ファイル
- `index.html` … 画面とゲームの進行
- `engine.js` … 質問の自動選択（候補を半分に割る質問を選ぶ）
- `kanji.json` … 漢字データ（学年・画数・読み・字の構成）

## 公開（GitHub Pages）
3ファイルを同じフォルダ（またはリポジトリ直下）に置いてPagesで公開します。
`fetch` でJSONを読むため、ファイルを直接開くと動きません。

## 仕組み
- 1問目は「ほぼ当たらないダミー質問」（有名な漢字）。当たったら「1問目で当たった！？」
- 以降は、残り候補をいちばん半分に割る質問を自動で選びます
  - 形：左右／上下／囲み／単純
  - 部品：「氵」「木」「言」「心」など、左側・右側の部品
  - 画数・学年：「◯◯より大きい？小さい？」（同じも選べる）
  - 読み：音読み・訓読みの有無、行（か行など）、よくある音
- 答えにくい質問は「わからない」で別の質問に変更できます
- 11問で絞りきれなければ、有力候補を順に提示（最大8字）

## 検証
全1,026字を「正しく答えるユーザー」として遊ばせると、**1,020字（99.4%）が11問以内で1字に特定**でき、
残り6字も候補2つまでに絞れます（最後の推測で救済）。
学年をいつも「わからない」にした場合は、約92%が1字に特定できます。

## 対象の漢字
文部科学省「学年別漢字配当表」（2020年度〜）の1,026字（1年80・2年160・3年200・4年202・5年193・6年191）。
旧データとの突き合わせで、新規追加の20字（茨・媛・岡…都道府県名の漢字）以外は一致を確認しています。
