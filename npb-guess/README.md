# 11問でプロ野球選手当て

思い浮かべたプロ野球選手を、最大11回の「はい／いいえ」で当てるWebアプリです。
「11問でポケモン当て」のプロ野球版として作りました（コードは独自実装）。

## ファイル
- `index.html` … 画面とゲームの進行
- `engine.js` … 質問の自動選択（候補を半分に割る質問を選ぶ）
- `players.json` … 選手データ（835人）

## 公開（GitHub Pages）
1. 3ファイルをリポジトリ直下に置く
2. Settings → Pages → Branch を `main` / `(root)` にして保存
3. `https://<ユーザー名>.github.io/<リポジトリ名>/` で遊べます

`fetch` でJSONを読むため、ファイルを直接ダブルクリックで開くと動きません（Pagesまたはローカルサーバー経由で開く）。

## 仕組み
- 1問目は「ほぼ当たらないダミー質問」（有名選手の名前）。当たったら「1問目で当たった！？」
- 2問目以降は、残り候補をいちばん半分に割れる質問を自動で選びます。
  球団・ポジション・投打・年齢・誕生月・身長・背番号・登録名の字 など
- 答えにくい質問（誕生日・身長・背番号）は少し後回しにする重み付けをしています
- 「わからない」で別の質問に変更可能
- 11問で絞りきれない場合は、有力候補を順に提示（最大8人）
- 結果画面から「答え合わせ」で、どの質問で食い違ったか確認できます

## 検証
全835人を「正しく答えるユーザー」として遊ばせるシミュレーションで、
**全員が11問（ダミー1問＋実質10問）で1人に特定**できることを確認しています。
ただし「わからない」を多用すると候補が残りやすくなります。

## データについて（要確認）
`players.json` は NPB公式サイトの「2026年度 選手一覧」（支配下選手、シーズン終了時点）を
もとに整形しました（背番号・投打・生年月日・身長・守備位置）。
同サイトには「掲載の情報の二次利用および無断転載を禁じる」旨の記載があります。
氏名・生年月日などの事実情報ではありますが、**公開前にご自身で利用条件をご確認ください**。
懸念があれば、選手データを自分で確認・整理したものに差し替えてください。
形式は `{"n":"名前","t":"球団コード","p":"P|C|I|O","no":"背番号","y":生年,"m":月,"d":日,"h":身長,"th":"右|左","bt":"右|左|両"}` です。
