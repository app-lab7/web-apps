# Score View（共和校・社員用）

入力状況・成績一覧・生徒別の過去成績を閲覧する画面です。
https://app-lab7.github.io/web-apps/score-viewer/

現在は既存Score Input APIのbootstrap/recordをGETで読みます。保存・削除・マスター更新は実装していません。データはメモリーに保持し、localStorageには保存しません。

0点を入力済みとして扱い、5科入力完了・一部入力・未入力・取得失敗を分けます。5科合計は全科に数値がある場合だけ表示します。年度・テスト・学年・学校、名前、状況で絞り込めます。

## 接続先も閲覧専用にする
既存入力APIには書き込み機能が残っています。画面の閲覧専用化だけでAPIの権限制御が完成するわけではありません。
1. 新しいApps Scriptプロジェクトに ReadOnlyAppsScript.gs を配置します。
2. スプレッドシートを読めるアカウントで、社員向けのアクセス設定でWebアプリとしてデプロイします。既存入力用のプロジェクトは置き換えません。
3. 新しいデプロイURLでbootstrap/recordの読み取りを確認します。
4. index.htmlのAPI定数をそのURLへ変更します。

ReadOnlyAppsScript.gsには保存・削除・編集トリガー処理がなく、POSTは常に拒否します。デプロイ管理の操作はこのリポジトリへの追加では実行されません。

## 読み込み
既存APIに一覧取得がないため、選択した対象の成績を最大4人ずつ取得します。学年・学校を先に絞ると待ち時間を減らせます。条件変更時は古いリクエストを中止し、通信失敗を未入力として数えません。刷新は「成績を読み込む」で行います。
