# ボカロ曲当て

思い浮かべたボカロ曲を、最大15問の質問で当てるWebアプリ（非公式・ファンアプリ）。

- 対象: ニコニコ動画で再生数100万回以上のボーカロイド系楽曲 1,013曲（2026年11月時点のスナップショット）
- 質問: ボーカル / 作者（投稿者）/ 投稿年 / 再生数 / 曲名の長さ・文字 / タグ由来の雰囲気
- 構成: 静的HTML + JS（`index.html` `engine.js` `songs.json`）。GitHub Pagesなどサーバー経由で開く必要あり

## データについて
- 出典: ニコニコ動画 スナップショット検索API v2（公開API）
- 「作者」は投稿者名ベースのため、カバー・再投稿は実際の作曲者と異なる場合あり
- 曲の雰囲気（ロック・和風・夏曲など）はニコニコ動画のタグ由来の目安
- 非公式であり、ニコニコ動画・各権利者とは無関係です
