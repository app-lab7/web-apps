# リリペン（Lyripen）

公開先: https://app-lab7.github.io/web-apps/utanote/

歌詞に記号・色・メモを書き込める、歌の練習用PWAです。
データは端末内のブラウザに保存されます。

## ホーム画面に追加

iPhone: Safariの共有 → ホーム画面に追加。
Android: ブラウザのメニュー → アプリをインストール。

## データの移行

旧URLで「使い方」→「バックアップをコピー」を選び、
新URLで「使い方」→「バックアップから復元」に貼り付けてください。
URLが変わるとブラウザの保存領域も変わるため、自動では移行されません。

## 更新

`utanote/` 配下のファイルを更新します。
オフライン用ファイルを変更したら `sw.js` のCACHE名を更新します。

## ライブ用プロンプター

曲の「歌う」→「ライブ用プロンプター」から、曲の長さ（10秒〜120分）、開始前のカウントダウン（0〜30秒）、文字サイズ、メモ表示、左右反転を設定します。設定は曲ごとに端末へ保存され、バックアップにも含まれます。

プレビューは停止状態で開き、「開始」でカウントダウン後にスクロールします。経過・残り時間、一時停止・再開、±10秒、シーク、先頭に戻す操作に対応。手で歌詞をスクロールすると一時停止し、その位置から再開します。画面が非表示になると一時停止し、戻った後の再開は手動です。対応端末では画面のスリープを抑止し、全画面表示も使えます。

Spaceで停止・再開（ボタンにフォーカス中はそのボタンを操作）、左右キーで±10秒、Escで終了。入力欄操作中はショートカットを止めます。

音声の再生・認識や音源との自動同期はありません。歌詞全体を指定時間で一定速度で送るため、間奏や歌唱速度に合わせ、リハーサルで手動の位置調整を確認してください。実機の画面・スリープ制御・全画面表示は端末やブラウザに依存します。
