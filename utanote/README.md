# リリペン（Lyripen）

公開先: https://app-lab7.github.io/web-apps/utanote/

歌詞に記号・色・メモを書き込める、歌の練習用PWAです。
データは端末内のブラウザに保存されます。

## ホーム画面に追加

iPhone: Safariの共有 → ホーム画面に追加。
Android: ブラウザのメニュー → アプリをインストール。

## データの移行

旧URLで「使い方」→「バックアップをコピー」を選び、
新URLで「使い方」→「バックアップから復元」に貼り付けてください。
URLが変わるとブラウザの保存領域も変わるため、自動では移行されません。

## 更新

`utanote/` 配下のファイルを更新します。
オフライン用ファイルを変更したら `sw.js` のCACHE名を更新します。
