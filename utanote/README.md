# リリペン（Lyripen）

公開先: https://app-lab7.github.io/web-apps/utanote/

歌詞に記号・色・メモを書き込める、歌の練習用PWAです。
データは端末内のブラウザに保存されます。

## ホーム画面に追加

iPhone: Safariの共有 → ホーム画面に追加。
Android: ブラウザのメニュー → アプリをインストール。

## データの移行

旧URLで「使い方」→「バックアップをコピー」を選び、
新URLで「使い方」→「バックアップから復元」に貼り付けてください。
URLが変わるとブラウザの保存領域も変わるため、自動では移行されません。

## 更新

`utanote/` 配下のファイルを更新します。
オフライン用ファイルを変更したら `sw.js` のCACHE名を更新します。

## ライブ用プロンプター

曲の「歌う」→「ライブ用プロンプター」で、各フレーズの表示秒数を0.1秒単位で設定します。歌詞の空行を除く1行が1フレーズです。開始・終了の時刻と全体の合計が入力に合わせて更新されます。「全体の時間から均等に分ける」で一括設定してから、各行を調整できます。合計120分まで。開始までの待ち時間（0〜30秒）は合計と別です。

「文字サイズ・メモなど」で文字サイズ、メモ、左右反転を変更します。「保存してプレビュー」は停止状態で開き、「開始」で動きます。秒数は曲ごと・行IDごとに保存し、並べ替えやバックアップからの復元でも行との対応を引き継ぎます。新しい行には全体時間からの初期値を入れ、削除した行の秒数は使いません。

設定した秒数を順に足した時刻でフレーズが切り替わります。現在のフレーズの記号・メモと、次のフレーズを表示。一時停止・再開、前後のフレーズ、シーク、先頭への移動に対応します。手動スクロールと画面が非表示になった場合は一時停止し、再開は手動です。Spaceで停止・再開（ボタン上ではそのボタンを操作）、左右キーで前後へ移動します。

音声の再生・認識や音源との自動同期はありません。リハーサルでタイミングを調整してください。全画面APIは標準・WebKitの両方を判定し、非対応や拒否時は操作欄を隠す表示拡大を使います。iPhoneでブラウザのアドレス欄を消す場合は、Safariからホーム画面に追加し、Webアプリとして開きます。実機の表示・スリープ抑止・全画面は端末とブラウザに依存します。

「歌う」の操作パネルは初期状態で折りたたみ、右下の「操作を開く」で展開します。開閉状態は表示設定として端末に保存します。展開時も画面の42%以内に収め、操作欄内をスクロールできます。折りたたみ中も自動スクロール中の停止ボタンを残します。

操作欄をたたむと、写真編集ツールのような丸いミニメニューになります。「歌う」の自動スクロールは、折りたたみ状態でも再生・一時停止・再開できます。ライブ画面の「たたむ」も再生を続けたまま前へ・一時停止／再開・次へ・操作を開くボタンに縮みます。ライブの操作欄の開閉では全画面状態やタイマーを変えません。

## 動画として保存

「歌う」→「操作を開く」→「動画として保存」。フレーズの表示時間設定画面から「この設定で動画を作る」も使えます。時間設定画面の未保存の秒数は、このボタンで保存して引き継ぎます。

横長1280×720・縦長720×1280を選択できます。歌詞、記号、範囲記号、ハイライト、行メモをCanvasへ描画します。メモ・次のフレーズ・左右反転・開始前の待ち時間の有無も選択できます。長い歌詞は折り返し・文字縮小し、収まらない場合は作成を開始しません。次のフレーズの予告のみ、長すぎる部分を省略します。

動画は音声なし。MediaRecorderの実行時対応を判定してMP4を優先し、WebMへフォールバックします。ファイルの拡張子は実際に返されたMIME形式に合わせます。端末内で30fps・目標1.8Mbpsの映像を実時間で記録するため、4分の動画の作成には約4分かかります。開始前の待ち時間を含め合計10分まで、チャンク合計150MiBを上限にします。画面を非表示にした場合は中止し、不完全な動画は保存しません。

完成後に動画プレーヤーで確認し、「ファイルに保存」または対応端末の「共有・写真に保存」を選びます。共有メニューの保存先はOSにより異なります。新しい設定に変更・画面を閉じる際には一時Blob URLと録画ストリームを破棄します。

検証：Canvasの実描画を横・縦それぞれPNG化して確認。模擬MediaRecorderによる形式選択・時間進行・ファイル作成・中止・エラー・リソース解放のテストを実施。iPhone実機のエンコード・再生・写真保存の一連の動作は未検証です。
