# 教室チャイム（iPad常設版）

## iPadでの使い方

1. 公開URLをSafariで開きます。
2. 共有ボタンから「ホーム画面に追加」を選びます。
3. ホーム画面の「チャイム」を起動します。
4. 最初に「音を有効化」を押し、試聴音を確認します。
5. 時刻・曜日・名前を登録します。
6. 「低照度モード」を押して常設表示にします。

## 推奨するiPad設定

- 充電器につないで使用してください。
- 消音モードと音量を確認してください。
- 「設定」→「画面表示と明るさ」→「自動ロック」を「なし」にします。
- 必要に応じて「設定」→「アクセシビリティ」→「アクセスガイド」で、このアプリに固定します。

## 重要

iPadが完全にロックされた場合、Webアプリの処理が停止することがあります。確実に鳴らすには、アプリを表示したまま低照度モードで運用してください。
