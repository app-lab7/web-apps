# 共和校 成績管理

社員向けの一覧入力・閲覧アプリ。保管先は既存の共和校スプレッドシートで、Score Input / Score View と共通。

ホーム：成績を入力 / 成績を見る / 入力状況を見る。学校・学年・年度・テストを順に選択し、一択は自動で進行。学校未設定の生徒も表示可能。

入力：5教科、詳細に偏差値・順位・回収・メモ。矩形の点数貼り付け、変更した生徒だけ保存。失敗した下書きは画面内に残す。再読み込み・離脱時に未保存確認。下書きは永続保存しない。

登録：生徒（ID自動発行）、学校、テスト（年度コピー）、学校平均。重複チェックと数式文字列の拒否。登録機能は capability manager:true の接続先でのみ有効。

`AppsScript.gs` は既存プロジェクトのコードを置換する完全版。既存の公開デプロイを新バージョンへ更新すると登録機能が有効になる。追加の認証機構は導入していないため、既存のアクセス設定で動作する。社員用という表示自体はアクセス制限ではない。

成績保存は直前の再取得で変更を確認し、更新版APIでは同じロック内でも expectedRecord を比較する。旧APIでは再取得と保存の間の競合は防げない。POSTの自動再試行は行わない。保存失敗時は入力を保持する。既存記録を明示的に消す削除機能は設けていない。

`?demo=1` は架空名簿で動作し外部APIには通信しない。学校平均や登録の挙動も確認できる。体験データはメモリだけ。

検証：`node --check app.js` / `node check.cjs`。保存・登録の実データ書き込みはテストに使わない。
