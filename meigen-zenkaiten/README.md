# 名言全回転大当りメーカー

好きな名言を入れると、パチンコ風の全回転演出で一節ずつ大当たりし、GIFにして保存できる単一ファイルのWebアプリ。

- 公開URL: https://app-lab7.github.io/web-apps/meigen-zenkaiten/
- 入力した言葉・履歴・背景画像は、閲覧者のブラウザ（localStorage）だけに保存されます。
- GIF書き出しはgifencを同梱しています（外部通信なし。フォントのみGoogle Fonts）。
